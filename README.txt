PREVIEW
Open index.html in a browser. An internet connection is needed for Google Fonts.
The bundled decorative image works locally.

PUBLISH ON APURWAL.IN
Upload index.html, script.js, and the assets folder together to your web root,
preserving their folder structure. Use HTTPS. No build or installation required.
This package does not publish or change your live website automatically.

LINK PREVIEW & FAVICON
assets/og-image.jpg (1200x630) is the image shown when the link is shared on
WhatsApp and other apps. The page tags point to https://www.apurwal.in/ — if the site
moves to a different address, update og:url, og:image and
the canonical link in index.html. The faces sit in the centre square so small
square thumbnails still show both of you. WhatsApp caches previews: after
publishing, share the link in a fresh chat; an older preview may take time to
refresh. The browser-tab icon and home-screen icons are the favicon*/icon*/
apple-touch-icon files in assets/. The design/ folder holds the source
illustration and preview-card layout; it does not need to be uploaded.
